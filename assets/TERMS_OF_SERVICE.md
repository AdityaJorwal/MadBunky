## 2. Description of the Service

MadBunky Pro is an **academic attendance management application** that provides the following core services:

- Attendance tracking and percentage calculation for academic subjects
- Smart "Bunk Budget" calculations (how many classes can be missed / must be attended)
- Weekly class scheduling and timetable management
- Optional automated attendance detection via GPS geofencing and WiFi network detection
- Rich notification system with actionable attendance marking
- Calendar integration (Google Calendar read-only sync)
- OCR-powered timetable scanning
- Cloud backup and restore via Google Drive (opt-in)
- Home screen widgets and Quick Settings tile (Android)
- Live Activities (iOS)

The App is intended for **personal, non-commercial use** by students to manage their own academic attendance records.
